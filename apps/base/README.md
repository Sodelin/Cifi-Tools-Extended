# CIFI Tools browser launcher — source preview

This experimental Android launcher opens the public CIFI Tools website in a browser. The browser owns its own sign-in session; this launcher does not receive browser credentials. It can also compare the bytes read from two user-selected files. Matching bytes do not prove backup validity, freshness, or account identity.

Game capture, automatic import, sync, and shared feature parity are not implemented in this source subset. Browser behavior, file-picker lifecycle and account sign-in have not been verified on an Android device for this source. The website and game are independent third-party services; this project is not represented as an official product.
